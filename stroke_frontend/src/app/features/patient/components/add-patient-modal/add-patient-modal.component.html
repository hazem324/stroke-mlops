Ajouter un nouveau patient

Le code patient est obligatoire. Le code patient est trop long.
Le prénom est obligatoire. Le prénom doit contenir au moins 2 caractères.
Le nom est obligatoire. Le nom doit contenir au moins 2 caractères.
La date de naissance est obligatoire. La date de naissance ne peut pas être dans le futur.
L'âge est obligatoire. L'âge doit être compris entre 0 et 120 ans.
Le poids est obligatoire. Le poids doit être compris entre 1 et 500 kg.
Le numéro de téléphone est obligatoire. Veuillez saisir un numéro de téléphone valide.
